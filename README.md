# Student Productivity Manager

## Overview
Student Productivity Manager is a Java-based desktop application developed to help students organize and manage their academic activities through a graphical user interface.

## Objectives
- Organize courses and academic schedules.
- Manage tests, projects, and tasks.
- Maintain attendance and academic scores.
- Store notes and student-related information.
- Provide a centralized interface for academic management.

## Features
- **Dashboard:** Central interface for accessing application modules.
- **Courses:** Manage course information.
- **Timetable:** Organize academic schedules.
- **Tests:** Manage test-related information.
- **Projects:** Track academic projects and deadlines.
- **Attendance:** Maintain attendance records.
- **Tasks:** Organize academic tasks.
- **Scores:** Record academic scores.
- **Notes:** Store useful academic notes.

## Technology Stack
- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Development Environment:** Visual Studio Code
- **Data Storage:** Local file-based storage

## Project Structure
The project is organized into Java source files containing the application entry point, graphical interface, data management components, and individual academic data models.

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that a compatible Java Development Kit (JDK) is installed.
4. Configure the Java environment if required.
5. Run `Main.java` to launch the application.
